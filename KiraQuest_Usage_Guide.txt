КАК ИСПОЛЬЗОВАТЬ ОБНОВЛЁННЫЙ ПРОМПТ KIRAQUEST

Этот промпт рассчитан на полноценное веб-приложение, а не на одну статическую HTML-страницу.

РЕКОМЕНДУЕМЫЙ СТЕК
- Next.js App Router + React + TypeScript — страницы, компоненты и серверная логика.
- Tailwind CSS + shadcn/ui + Lucide React — единый адаптивный интерфейс и иконки.
- Supabase — PostgreSQL, регистрация/вход и сохранение прогресса.
- Zod — проверка данных; Vitest для логики и Playwright для основных пользовательских сценариев, если доступно.
- GitHub — история изменений; Vercel — удобный вариант публикации Next.js-приложения.

ПОШАГОВО
1. Открой папку проекта в VS Code.
2. Открой Codex или GitHub Copilot в режиме работы с проектом и передай файл KiraQuest_prompt_1500_lines.txt.
3. Попроси сначала прочитать весь проект и составить план. Не разрешай удалять рабочие файлы, пока ИИ не объяснит, что они делают.
4. Пусть ИИ реализует только первый этап, запустит приложение, проверит ошибки и покажет результат. Затем переходите к следующему этапу.
5. Для полноценной серверной версии создай проект Supabase и заполни локальный .env.local по инструкции, которую подготовит ИИ. Не присылай ключи в чат и не добавляй .env.local в Git.
6. Если Supabase пока не настроен, сначала проверь демо-режим: проект должен открываться и показывать функции, но честно указывать, что локальный прогресс не синхронизируется с аккаунтом.
7. Перед защитой попроси ИИ выполнить TypeScript/type-check, lint, тесты и production build и объяснить, что реально прошло.
8. Для публикации можно использовать GitHub + Vercel, а Supabase оставить базой данных. Следуй актуальным официальным инструкциям и проверь все переменные окружения в настройках опубликованного проекта.

ВАЖНО
- Не требуй от ИИ сделать весь проект одним огромным шагом.
- Не вставляй секретные ключи в исходный код или в публичный чат.
- Supabase требует корректных политик Row Level Security (RLS); одной авторизации недостаточно для защиты пользовательских данных.
- Не добавляй настоящие платежи в учебную версию. Магазин маскотов и косметики может работать на виртуальных жетонах.
- Сначала доведи до конца базовый путь: открыть приложение → выбрать маскота → выбрать курс → пройти урок → получить XP → увидеть сохранённый прогресс.
