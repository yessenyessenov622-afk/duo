# KiraQuest — старая HTML-демоверсия

Это сохранённая копия прежней демоверсии. Она остаётся без React и Next.js и продолжает использовать свои файлы в этой папке.

## Запуск

В терминале из корня проекта выполните:

```powershell
Set-Location legacy-demo
python -m http.server 5173
```

Затем откройте `http://localhost:5173`. Если порт 5173 занят, укажите другой свободный порт, например `5174`.

Данные старой версии сохраняются в `localStorage` браузера. С серверной частью они не синхронизируются.
