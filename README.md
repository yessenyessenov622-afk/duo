# KiraQuest

Учебное веб-приложение с короткими курсами, маршрутами и поддерживающими персонажами. Новая версия использует Next.js App Router, React и TypeScript. Исходная HTML/CSS/JavaScript-демоверсия сохранена в `legacy-demo/`.

## Требования

- Node.js 20.9 или новее (для локальной работы рекомендуется актуальная LTS-версия).
- npm.

## Новая версия: установка и запуск

```sh
npm install
npm run dev
```

Откройте `http://localhost:3000`.

Проверка типов и production build:

```sh
npm run typecheck
npm run build
npm start
```

`npm start` запускает production-сборку и выполняется после `npm run build`.

## Старая демоверсия

Исходная версия сохранена отдельно и не зависит от Next.js:

```powershell
Set-Location legacy-demo
python -m http.server 5173
```

Откройте `http://localhost:5173`. Исходные файлы в корне проекта также оставлены на месте.

## Структура новой версии

- `app/` — App Router: главная, интерактивная карта, короткие уроки, маскоты, профиль и студия.
- `src/components/` — оболочка, навигация, карта пути, задания и персонализация.
- `src/data/` — типизированные маскоты и демомаршруты языковых, технических, ИКТ- и инженерных курсов.
- `src/types/` — типы навигации, настроек, уроков и локального прогресса.
- `src/lib/` — безопасные адаптеры локальных настроек и прогресса.
- `src/styles/` — дизайн-система, персонализация и адаптивная карта.
- `legacy-demo/` — автономная копия прежней HTML/CSS/JavaScript-версии.

## Текущее состояние

Главная показывает честное пустое состояние без выдуманной статистики. На `/map` доступны двенадцать учебных направлений, 52 темы и 104 коротких урока, включая четыре курса по ИКТ и четыре курса по машиностроению. Задание на `/lessons?lesson=<id>` проводит по рабочему циклу: ответ, объяснение, завершение, XP и открытие следующего шага. Карта использует существующий ключ демопрогресса `kiraquest.progress.v1` и ID уроков исходного каталога; завершения, XP, жетоны и даты активности читаются прежней демоверсией. Выбранный фильтр карты хранится отдельно.

Спутника можно выбрать в `/mascots`; тема, акцент, фон, аксессуар и настройки — в `/studio`. Гостевой прогресс хранится в браузере. В проекте подготовлены вход через Google, серверное сохранение в PostgreSQL и перенос гостевых данных; для их работы владелец должен настроить HTTPS, OAuth и базу. На публичном HTTP-адресе вход отключён. Настройка и ограничения описаны в [docs/auth-setup.md](docs/auth-setup.md). Таблицы лидеров и панели владельца пока нет. Звуковые эффекты пока не реализованы.

Старая демоверсия сохраняет данные в `localStorage` текущего браузера и не синхронизирует их с аккаунтом или сервером.
