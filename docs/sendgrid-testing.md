# Проверка почты через SendGrid

Поддержка SendGrid предназначена для проверки реальной доставки кодов подтверждения и ссылок восстановления. Она не активируется автоматически и не заменяет надёжную production-почту.

1. Создайте аккаунт [SendGrid](https://signup.sendgrid.com/) и завершите его проверку. В **Settings → Sender Authentication** подтвердите адрес отправителя через **Single Sender Verification** либо настройте свой домен. Для Single Sender используйте именно подтверждённый адрес. Проверьте, разрешает ли ваш аккаунт отправку через Email API: официальная [инструкция Single Sender](https://www.twilio.com/docs/sendgrid/ui/sending-email/sender-verification) описывает тестовый вариант, но [справка](https://help.twilio.com/articles/47453602998171) указывает на ограничение Email API. Адреса бесплатных почтовых сервисов могут отклоняться или попадать в спам из-за DMARC.
2. Создайте API key с минимальным разрешением **Mail Send**. Ключ и пароли не отправляйте в чат и не добавляйте в Git. При вводе настройки на сервере через закрытый редактор `/etc/kiraquest/kiraquest.env` сохраните имеющиеся секреты и адрес базы без изменений.
3. На сервере укажите `KIRAQUEST_MAIL_MODE=sendgrid`, `SENDGRID_API_KEY` и `KIRAQUEST_MAIL_FROM`. Значение `KIRAQUEST_MAIL_FROM` должно быть только подтверждённым email без имени и угловых скобок. Также нужны `BETTER_AUTH_URL` с точным HTTPS-адресом, существующие `DATABASE_URL` и `BETTER_AUTH_SECRET`, а для парольного входа — `KIRAQUEST_PASSWORD_AUTH=enabled`. Перед активацией нужны резервная копия и проверка доставки; настройки не включены автоматически.
4. После обновления приложения и перезапуска проверьте доставку тестовому получателю, подтверждение почты, вход, выход и восстановление пароля. Ответ SendGrid `202` означает, что запрос принят, а не что письмо доставлено: проверьте сам ящик и спам.

Новые аккаунты имеют [60-дневный пробный период](https://www.twilio.com/docs/sendgrid/ui/account-and-settings/upgrading-your-plan), после которого для продолжения отправки требуется подходящий платный тариф. Условия существующего аккаунта могут отличаться. Для постоянной эксплуатации требуется отдельно выбрать почтовый сервис и проверить его тариф, аутентификацию домена и доставляемость. Настройка API и пробный доступ не подтверждают работу доставки.
