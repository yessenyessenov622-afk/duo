# Исправления ревью оформления — 27 октября 2026

## Что изменено

- `lastLightTheme` хранится вместе с оформлением. Быстрый переключатель восстанавливает выбранную светлую тему после перезагрузки.
- У акцента два явных режима: встроенный цвет темы и собственный цвет. При переходе со старых настроек стандартный лавандовый акцент считается цветом темы; отличающийся сохранённый цвет сохраняется как пользовательский.
- Палитры и расчёт контраста собраны в `src/lib/appearance.ts`. Читаемый оттенок акцента рассчитывается для поверхности, фона страницы и мягкого фона; цвет текста на акцентной кнопке выбирается отдельно. Исходный пользовательский цвет не теряется.
- Нечитаемые значения не запрещают сохранить выбор: интерфейс объясняет автоматическую коррекцию оттенка. Фокус клавиатуры имеет двухцветную обводку.
- Тёмные стили покрывают вложенные индикаторы карты, статусы уроков, диалоги, варианты ответа и результат. Состояния правильного и неправильного ответа имеют отдельные цвета.
- Размеры шрифтов переведены в rem, включая подписи карты и студии. Компактная плотность затрагивает студию, карту и уроки; размеры кнопок ответа сохраняют минимум 44 px.
- Студия использует модель «изменить → посмотреть образец → сохранить». Образец показывает акцент, текст и отступы. Текст интерфейса прямо говорит, что остальные страницы изменятся после сохранения. Отмена возвращает сохранённые параметры.
- Ошибки чтения и записи настроек видны в общем сообщении. Некорректные данные нормализуются в памяти и могут быть перезаписаны явным сохранением. Неудачная запись не заменяет текущие настройки и не уничтожает черновик при сбросе.
- Скрипт в корневом layout применяет сохранённую тему до гидратации; провайдер не перезаписывает её исходной темой при первом эффекте.

## Повторение браузерной проверки

Используйте Node.js не ниже 20.19.0. Запустите production-сервер в отдельном терминале:

```powershell
npm run build
node node_modules/next/dist/bin/next start -H 127.0.0.1 -p 3189
```

Создайте отдельный временный профиль Chrome: сценарий меняет демо-прогресс и оформление в localStorage этого профиля.

```powershell
$reviewProfile = Join-Path $env:TEMP ('lifeskill-review-' + [guid]::NewGuid())
$reviewChrome = Start-Process -FilePath 'C:\Program Files\Google\Chrome\Application\chrome.exe' -ArgumentList @('--headless=new', '--disable-gpu', '--no-first-run', '--remote-debugging-port=9333', "--user-data-dir=$reviewProfile", 'about:blank') -WindowStyle Hidden -PassThru
node scripts/check-appearance.mjs
Stop-Process -Id $reviewChrome.Id
```

Сценарий не требует дополнительных npm-зависимостей. По умолчанию JSON-результат и PNG сохраняются в `%TEMP%\lifeskill-appearance-review-artifacts`. При необходимости задайте `REVIEW_OUTPUT`, `REVIEW_APP_URL` и `REVIEW_CDP_URL` через переменные окружения.
