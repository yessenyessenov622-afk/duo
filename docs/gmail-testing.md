# Тестовая почта через Gmail

Используйте отдельный личный Gmail-аккаунт с двухэтапной защитой. В Google создайте пароль приложения для KiraQuest; основной пароль Google вводить в KiraQuest не нужно. Пароль приложения даёт доступ к почте, поэтому не отправляйте его в чат и не сохраняйте в Git. SMTP соединяется с `smtp.gmail.com:465` с проверкой TLS-сертификата.

После публикации кода откройте интерактивную сессию AWS Systems Manager Session Manager на существующем EC2 и запустите:

```sh
sudo python3 /opt/kiraquest/scripts/configure-gmail.py
```

Введите адрес Gmail и пароль приложения в ответ на запросы; ввод обоих значений скрыт. Если программа отказывает из-за отсутствия интерактивного терминала, не вводите секрет другим способом в журналируемую команду. Программа сохраняет значения в закрытом серверном файле и оставляет парольную авторизацию выключенной. После этого сообщите о завершении настройки, не сообщая ни пароль, ни содержимое файла.

Перед включением авторизации необходимо проверить доставку настоящего тестового письма, затем подтверждение регистрации, вход, выход, восстановление пароля и синхронизацию с другого устройства. Google может ограничивать отправку; это решение подходит для небольшого теста, а не как гарантия постоянной публичной почтовой службы.
